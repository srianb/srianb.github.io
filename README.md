# Srian Buvaneka Bulathsinhala - Portfolio Website

A professional portfolio website showcasing the career, experience, and expertise of Srian Buvaneka Bulathsinhala, a seasoned Technical Content Strategist with 25+ years of experience.

## 🎯 Project Overview

This is a modern, responsive single-page portfolio website built with clean HTML5, CSS3, and JavaScript. The website presents a comprehensive view of Srian's professional journey, including his extensive experience in technical writing, documentation management, and knowledge base implementation.

## ✨ Features

### Currently Completed Features

- **Hero Section**: Eye-catching introduction with professional statistics and profile image
- **About Section**: Comprehensive overview of professional background and expertise
- **Experience Timeline**: Interactive timeline showcasing 25+ years of professional experience across 5 major organizations
- **Skills Showcase**: Organized display of technical writing skills, tools, and competencies
- **Education Section**: Educational background information
- **Contact Section**: Professional contact information with LinkedIn integration
- **Responsive Design**: Fully responsive layout that works seamlessly across all devices (desktop, tablet, mobile)
- **Smooth Animations**: Fade-in animations and scroll-based effects for enhanced user experience
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Scroll-to-Top Button**: Convenient button for quick navigation back to top
- **Active Navigation Highlighting**: Dynamic navigation highlighting based on scroll position

### Design Features

- Modern gradient backgrounds
- Clean typography using Inter font family
- Professional color scheme (blue primary colors)
- Smooth transitions and hover effects
- Card-based layouts for better content organization
- Icon integration using Font Awesome
- Optimized for performance and accessibility
